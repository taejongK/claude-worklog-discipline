### 문서 구조 (research)

```
docs/
  index.md               문서 목차·요약·링크
  worklog/{YYYY_MM_DD}.md  날짜별 작업 로그
  report/                주요 실험 결과·보고서
  reference/             조사 자료 원본
```

### 실험 결과가 나오거나 보고서를 쓸 때 (docs/report)

```
작업 항목에 담기엔 긴 내용(실험 결과, 설계 대안 비교, 디버깅 과정, 분석)은
docs/report/{YYYY_MM_DD}_{주제}.md 로 쓰고, 그날 worklog 작업 항목에 링크를 남긴다:
  - 보고서: [{주제}](../report/{YYYY_MM_DD}_{주제}.md)
- 구성: 목적 / 방법(설정·데이터) / 결과(수치·표) / 해석 / 남은 질문
- 근거로 쓴 자료는 docs/reference/ 의 원본에 링크한다.
- 같은 주제를 이어가면 기존 보고서를 갱신한다.
```

### 자료를 조사했을 때 (docs/reference)

```
보고서 작성이나 작업에 참고하려고 조사한 자료의 원본을 docs/reference/ 에 저장한다.
- 요약하지 말고 원본 그대로 저장한다 (웹 문서는 본문 + 출처 URL + 수집일).
- 파일명: {주제}_{출처}.{확장자}
```
